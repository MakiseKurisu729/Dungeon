# Docs — 文档总览与目录职责

本目录是项目文档的唯一存放位置（不放入 `Assets/`，不生成 Unity `.meta`）。

> 新会话先读根目录 `AGENTS.md`（规则书），再读事实基线、`交接/当前状态.md` 和当前任务包。
> 流程规则唯一入口是 `AGENTS.md`；执行细则见 `交接/工作流规则.md`。

## 目录职责

| 位置 | 职责 |
|---|---|
| `00_项目事实基线.md` | **当前事实，不是规划。** 记录仓库已核验事实、用户报告待复验项、目标设计、尚未实现项和未知项。 |
| `01_总体架构与内容生产规范.md` | 目标架构、内容生产规范与**架构不变量**。 |
| `02_Unity63迁移及毕业设计实施计划.md` | Unity 6.3 迁移与毕业设计实施计划。 |
| `04_可复用资产与编辑器工具设计清单.md` | 可复用资产与编辑器工具清单。 |
| `06_测试架构与验收分层.md` | 测试架构、验收分层与套件说明。 |
| `07_工程规范与基础设施.md` | 工程规范、基础设施缺口、排期与暂缓项。 |
| `交接/` | 当前状态、任务书、执行报告、模板、工作流细则。 |
| `规范/` | spec 层：`项目宪法.md`（Mission / Scope / Tech stack，1 页索引）与 `规范说明.md`（课程 spec → 本项目产物映射）。 |
| `决策/` | 重要且不易逆转的决策（ADR）。动画槽位化与子状态机见 `ADR-0003`。 |
| `学习/` | 学习讲稿：`<ID>_讲稿.md`，模板 `讲稿模板.md`（AI 初稿 + 所有者批注）。 |
| `QA/`、`QA/Evidence/` | **验收证据（机器目录，保留英文路径以免断链）**：真实验收记录和证据。只写真实执行结果。 |
| `归档/` | 历史资料（含 `03`、`05`），**不作为当前事实，也不作为开工依据**。 |

## 交接目录里的关键文件

| 文件 | 用途 |
|---|---|
| `交接/当前状态.md` | 状态唯一入口：分支、HEAD、当前任务、禁止事项、下一会话第一步。 |
| `交接/M7_决策结论.md` | M7 决策 D1–D20 + 长任务计划（提交/回退/停止/目检）。 |
| `交接/交接_M7.md` | M7 审计背景与原始 D1–D12。 |
| `交接/工作流规则.md` | 工作流细则：TASK/REPORT 模板、AC 表、证据、提交与分支、前置清单、风险、停止、讲稿、Replanning、Done 门槛、模型与钱包路由。 |
| `交接/任务模板.md`、`交接/报告模板.md` | 三节 TASK 模板、REPORT 模板（含 AC 回填与 `文件:行`）。 |
| `交接/TASK_*.md`、`交接/REPORT_*.md` | 任务包与执行报告；历史文件保留 `TASK_`/`REPORT_` 前缀 + ID，便于追溯。 |
| `交接/醒来目检清单_*.md` | 长任务结束后供所有者逐项目检。 |

## 阅读顺序建议

1. `AGENTS.md`（规则书）
2. `Docs/00_项目事实基线.md`（当前事实）
3. `Docs/交接/当前状态.md`（当前进度与下一步）
4. `Docs/规范/项目宪法.md`（Mission / Scope / Tech stack）
5. `Docs/交接/TASK_*.md`（本次任务的边界与验收）
6. 需要设计背景时再读 `01`/`02`/`04`/`06`/`07`；需要历史背景时才读 `归档/`
