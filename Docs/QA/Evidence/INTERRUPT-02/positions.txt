[与工单 §2A 目标表的差异（2 处，均为「不穿块」服务）]
1. AnyState：工单建议 (520, -160)。实测该位置会让 AnyState->Hit_A 变成沿 x=520 的竖直长线，
   从 y=-160 直下到 770，**穿过 AttackMelee / Attack_Draw / Attack_Release / Bash / Skill 五个状态块**。
   改为 (300, 600)（col1 与 col2 之间的空走廊、Locomotion 行左侧），AnyState->Hit_A / AnyState->Downed 变成斜线，
   只走空走廊与 Downed 列外侧。
   注：`AnimatorStateMachine.anyStatePosition` 实际是公开可写属性，不需要工单预期的 `SerializedObject` 反射；
   已用该属性写入并 AssetDatabase.SaveAssets()。
2. AnyState 纵向位置最终取 (300, 600) 而非 (300, 620)：620 会让 Skill->Locomotion 这条横线穿过 AnyState 节点本身。

[连线穿块分析（估算）]

连线按「节点中心→节点中心」求交（Unity 实际连的是边框，误差约 ±15px）。因此**最终以所有者目检为准**，
