## 2. 定向问题回答

### 2.1 空技能槽（E/R）行为
- L117 `var s = ss.GetSkill(i);`
- L118 `if (s == null || s.effects == null || s.effects.Length == 0) continue;`
- **结论：`continue`，无任何 Console 输出、无 UI 提示、无指示器。属设计内静默**（工单 §1.2 非目标，本单不修，登记未决项）。

### 2.2 指示器地面投影是否依赖 NavMesh / Physics
- `SkillIndicator.UpdateVisual`（`SkillIndicator.cs:45-59`）：
  - 范围圈：L47-51 纯 `Mathf.Cos/Sin` 生成圆周点，`y=0.05f`。
  - 指向线：L53 调 `CursorGroundPoint(center)`；L61-69 用 `Camera.main.ScreenPointToRay(Input.mousePosition)` 与 **`y=0` 平面求交**：`t = -ray.origin.y / ray.direction.y`，`t > 0` 时返回交点。
  - 落空（射线平行或 t ≤ 0）：L69 返回 `fallback`（施法者位置），不抛异常。
  - 无 `Physics.Raycast`、无 `NavMesh` 调用、无 `try/catch` 吞异常。
- **结论："指示器依赖 NavMesh / 射线导致静默失败"不成立**。指示器渲染与导航完全解耦；它只是没有任何人调用 `Show()/UpdateVisual()`（因为 `SkillInputController.Update()` 不存在）。

### 2.3 `skillKeys` 序列化
- L22 `public KeyCode[] skillKeys = { Q, W, E, R };` —— **逐实例序列化数组**。组件一旦缺失，按键映射不会自动补回，必须重新挂组件并保留默认值。
