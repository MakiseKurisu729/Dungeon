# 证据 — 验收证据

本目录存放 `Docs/QA/` 记录所引用的真实证据：截图、录屏、Console/Player 日志、命令输出。

## 命名建议

```
任务ID_功能_日期_序号.扩展名
```

示例：

- `FND-00B_移动_2026-11-05_01.png`
- `FND-00B_迷雾_2026-11-05_02.mp4`
- `FND-00B_团灭_2026-11-05_03.log`

规则：

- 日期使用 `YYYY-MM-DD`。
- 序号两位，从 `01` 开始，同一功能同一天内递增。
- 一个证据只对应一个功能点，避免一张图证明多件事。
- 在 QA 记录中使用相对路径引用，例如 `Evidence/FND-00B_移动_2026-11-05_01.png`。

## 当前状态

本目录按任务号存放真实证据，已有 `M7-0`、`QA-REFACTOR-01`、`SPEC-01` 等任务目录。新增证据按 `<任务ID>/` 建子目录；canonical 套件目录只追加不覆盖。

同意事项：

- 无证据的条目必须在 QA 记录的"证据"字段写 `无`。
- 不得使用占位图、伪造日志或截取自其他版本的画面充当证据。
