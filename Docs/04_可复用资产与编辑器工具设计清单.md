# 魔石地牢：可复用资产与编辑器工具设计清单

> 文档版本：v1.0（仅设计，不含工具原型或项目修改）  
> 编制日期：2026-11-01  
> 优先级：P0＝阻塞后续内容生产；P1＝主要内容需要；P2＝有余力再做。  
> 状态：“已有”仅表示仓库存在对应资产；“设计”表示后续新建或重构，未表示实现。

## 1. 可复用编辑器工具

### 1.1 P0：先建立工程安全与内容校验

| ID | 工具 | 状态 | 输入与输出 | 核心功能 | 验收标准 |
|---|---|---|---|---|---|
| ED-01 | Project Doctor 工程体检 | 设计 | 读取场景、预制体、包和设置；输出 HTML/Markdown 报告 | 缺脚本、关键空引用、重复管理器、旧 Input、全场扫描、直接 Destroy、运行时材质实例、包版本与目录检查 | 对当前仓库能列出真实问题；修复后对应项消失；不误把测试白名单当错误 |
| ED-02 | GUID-Safe Data Migration | 设计 | `Date` 与目标 `Data`；输出迁移和引用报告 | 仅在编辑器内移动资产、保留 `.meta`/GUID、检查引用；提供干运行，不自动删除旧目录 | 干运行不写文件；迁移后技能/单位/武器引用不变，GUID 前后一致 |
| ED-03 | Content Validator 数据校验 | 设计 | 全部定义资产与索引；输出错误定位 | 稳定 ID 唯一、必填引用、数值范围、职业/技能/效果/状态组合合法性 | 重复 ID、空效果、负冷却等能被定位到具体资产；正式构建可阻止严重错误 |
| ED-04 | Unit Prefab Validator | 设计 | 单位预制体；输出组件与层级报告 | 检查 Stats、Team、Health、Registry、NavMeshAgent、Animator、Hurtbox、Socket、UIAnchor 和网络组件 | 对现有三职业和骷髅给出可执行修复清单；合法基础变体通过 |
| ED-05 | Animator Audit | 设计 | Controller、Override、动作数据；输出差异报告 | 检查单层、状态/参数、Any State、自过渡、Draw/Release、Override 缺剪辑、Culling、攻击状态引用 | 能发现缺失 `Attack_Release`、错误 Trigger、空 Override 和代码状态名不匹配 |
| ED-06 | Pool Lifecycle Audit | 设计 | 池化预制体和调用点；输出借用/归还检查项 | 检查直接销毁、超时回收、Trail/计时器/目标/事件订阅重置项 | 连续借还 100 次测试无状态残留；漏归还对象有明确日志 |
| ED-07 | Scene Template Wizard | 设计 | 场景类型和名称；生成测试/楼层场景 | 按模板创建 `[WORLD]`、`Environment`、`LevelGraph`、`Gameplay`、`Camera` 等根节点和必要服务 | 新场景不复制应用管理器；通过 Scene Validator；可从 Boot 正常进入 |

| ED-15 | Playtest Recorder | 设计 | 运行事件与队伍配置；输出 JSON/CSV | 记录路线、战斗、资源、倒地、撤离、版本和随机种子；提供隐私友好的本地导出 | 同一局日志可关联楼层/队伍/版本；字段完整；可生成研究统计表 |

### 2.3 环境模块最小套件

每层不需要立即制作大量独立模型，先具备可复用灰盒/正式模块：直通道、宽通道、转角、十字/T 形连接、门、房间、核心大厅、上下层连接、遮挡体、危险区边界、休整节点、资源节点、首领场地、撤离场地和地标。所有模块使用同一连接与碰撞规范，主题层通过视觉 Variant 区分。
