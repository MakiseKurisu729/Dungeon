## 4. 每批动作清单（执行者按序执行）

1. 读 `editor_state`：`is_compiling=false`、`is_domain_reload_pending=false`；活动场景非脏。
2. 建目标文件夹（`manage_asset action=create_folder`）。
3. **单文件试跑移动** → `git status` 验证 `.cs`+`.meta` 成对 → 再批量。
4. 批量移动本批文件（`manage_asset action=move`；失败退化为文件系统成对移动）。
5. 加命名空间（块级 `namespace X { … }`，内容整体右移 4 空格；Unity 2022.3 是 C# 9，**不能用文件级 namespace**）。
6. 补 `using`：按 `error CS0246/CS0234` 逐条修，测试同步；不改逻辑、不改类型名、不改字段名。
7. `refresh_unity` → 等编译结束 → `read_console` 过滤 error → 0 条才继续。
8. `py -3.12 -X utf8 Docs/QA/Evidence/M7-1/audit_scripts.py` → 复制输出到 `批N/audit/`。
9. `py -3.12 -X utf8 Docs/QA/Evidence/M7-1/verify_m7_1.py --base 483678fb` → 全 PASS。
10. `execute_menu_item` 跑 `REFACTOR` → 记录 `Summary` 的 `pass/fail` 与 `InEditorResult.txt` 的 `code`；再跑 `SPEC01`。
11. 批 2/批 4 追加 Play 30 秒冒烟（进 Play → 30s → 读 Console → 退出 Play；**不保存、不改对象**）。
12. 写证据 → `git status` 核对 → `git add -- Assets/_Project/Scripts` + 显式 Docs 路径 → commit → 记录 hash。
