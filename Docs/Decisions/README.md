# Decisions — 架构与协作决策记录（ADR）

本目录记录**重要且不易逆转**的决策。

## 何时写 ADR

- 决策会影响多个后续任务，或推翻成本较高。
- 决策改变了文档体系、协作路由、事实来源的权威性。
- 存在被否决的备选方案，需要留下理由。

日常小改动、临时排查、单次实现细节**不需要**写 ADR。

## 规则

- 一个决策一个文件，命名 `ADR-000N_简述.md`。
- 状态取值：`Proposed` / `Accepted` / `Superseded` / `Deprecated`。
- ADR 一经 `Accepted` **不得改写历史结论**；需要改变时新建 ADR，并在旧 ADR 中标注 `Superseded by ADR-000X`。
- 日期使用实际决策日期。
- 本任务（FND-00A）只为两项基础决策补写 ADR，**不为历史架构决定批量补写**。
