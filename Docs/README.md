# Docs — 文档入口与目录职责

本目录是项目文档的唯一存放位置（不放入 `Assets/`，不生成 Unity `.meta`）。

> 新会话先读根目录 `AGENTS.md`，再读事实基线、`CURRENT.md` 和当前任务包。

## 目录职责

| 位置 | 职责 |
|---|---|
| `00_项目事实基线.md` | **当前事实，不是规划。** 记录仓库已核验事实、用户报告待复验项、目标设计、尚未实现项和未知项。 |
| `01`～`05` | 已提供的设计、计划和协作基线（目标架构、迁移与实施计划、通用 AI 协作规则、资产与工具清单、当前阶段人工协作规则）。 |
| `Tasks/` | 当前及历史任务包。每个任务一个文件，状态见任务包头部。 |
| `QA/` | 真实验收记录和证据。只写真实执行结果。 |
| `Decisions/` | 重要且不易逆转的决策（ADR）。 |
| `Handoff/CURRENT.md` | 当前交接入口：分支、提交、当前任务、禁止事项、下一会话第一步。 |
| `Archive/` | 历史资料，不作为当前事实。 |

## 设计文档索引

| 编号 | 文件 | 用途 |
|---|---|---|
| 01 | `01_总体架构与内容生产规范.md` | 目标架构与内容生产规范 |
| 02 | `02_Unity63迁移及毕业设计实施计划.md` | Unity 6.3 迁移与毕业设计实施计划 |
| 03 | `03_AI协作与项目交接文档.md` | 通用 AI 协作与交接规则 |
| 04 | `04_可复用资产与编辑器工具设计清单.md` | 可复用资产与编辑器工具清单 |
| 05 | `05_Agent工作流人工协作与毕设基石重构指南.md` | 当前阶段人工协作与基石重构指南 |

以上 01～05 为设计与计划基线，其中描述的"目标能力"不等于"已实现能力"。任何"是否已经可用"的判断，必须回到 `00_项目事实基线.md` 与 `QA/` 的真实记录。

## 阅读顺序建议

1. `AGENTS.md`（协作入口与硬约束）
2. `Docs/00_项目事实基线.md`（当前事实）
3. `Docs/Handoff/CURRENT.md`（当前进度与下一步）
4. `Docs/Tasks/<当前任务>.md`（本次任务的边界与验收方式）
5. 需要设计背景时再读 `01`～`05`；需要历史背景时才读 `Archive/`
