# 07 工程规范与基础设施清单

> 用途：把“工程规范、基础设施缺口、排期与暂缓项”集中在一处，避免同一决定在多个文档里各说一套。
> 上位文档：`AGENTS.md`（规则书）、`Docs/01_总体架构与内容生产规范.md`（架构不变量）、`Docs/02_Unity63迁移及毕业设计实施计划.md`（里程碑）。
> 本文件只登记“要不要做、什么时候做、代价多大”，不复述架构结论。
> 最后更新：2026-11-06（DOC-INFRA-01）

## 0. 字段与取值

- 字段固定：`ID / 是什么 / 现状 / 标准做法 / 收益 / 成本 / 风险 / 状态 / 排期`，一项一行。
- 状态只有五种：`已批准`（定案、可开工）/ `进行中` / `待排期`（认可，未定时间）/ `暂缓`（有触发条件再议）/ `不做`（已否决，理由留档）。
- 状态只由所有者变更为上列五值之一；某条做完后由所有者删除该行（或移到“已完成”附录），改状态需同步 `Docs/交接/当前状态.md`。
- 数量口径：除特别注明，脚本统计范围是 `Assets/_Project/Scripts`（77 个 `.cs`），测试统计范围是 `Assets/_Project/Tests`。复核命令见 §5。

## 5. 复核方法

数字均可复算，命令在仓库根执行（PowerShell）：

```powershell
$s = Get-ChildItem Assets\_Project\Scripts -Recurse -Filter *.cs
$s.Count                                                        # 77 脚本
($s | Select-String '^\s*namespace\s').Count                    # 0 namespace
($s | Select-String 'Debug\.Log').Count                         # 23 处日志
($s | Select-String '(?<![\w.])Input\.(GetKey|GetKeyDown|GetKeyUp|GetMouseButton|GetMouseButtonDown|GetMouseButtonUp|GetAxis|GetAxisRaw|anyKey|mousePosition)\b').Count   # 38 legacy Input
(Get-ChildItem Assets -Recurse -Filter *.asmdef).Count          # 0 asmdef
git ls-files "*.csproj"                                         # 两个 csproj 仍被跟踪
```

测试规模（TEST-03 口径）：

```powershell
$t = Get-ChildItem Assets\_Project\Tests -Recurse -Filter *.cs
$t.Count                                                    # 29 个 .cs（runtime 21 + editor 8）
($t | Get-Content | Measure-Object -Line).Lines             # 12,253 行
($t | Where-Object { $_.FullName -match '\\Runtime\\' }).Count   # 21
($t | Where-Object { $_.FullName -match '\\Editor\\' }).Count    # 8
```

测试框架现状（TEST-02 口径）：全仓 `Assets/**/*.cs` 中 `using NUnit`、`[Test]`、`[UnityTest]`、`UnityEngine.TestTools` 命中数均为 0，测试靠自研探针 + 协程断言。
