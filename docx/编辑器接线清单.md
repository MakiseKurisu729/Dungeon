# 编辑器接线清单（检查器拖线对照表）

> 用法：按物体逐个核对"槽 ← 拖什么"。凡标 🔴 的是功能断点槽（空了就静默失灵）；
> ⚠️ 是这次"按 Q 没反应"的优先排查区。
> 本表基于 Scripts 全量代码生成（2026-10-31）。

## 一、场景物体

### Managers（场景根下的空物体）
| 组件 | 槽 ← 拖什么 |
|---|---|
| SelectionManager | 无拖线槽（代码自动） |
| CursorManager | 无拖线槽 |
| Debug Camera Switcher | Cam ← 层级 PlayerCameraRoot 下的 Main Camera；Look Target ← 场景 Knight_Unit；Focus Target ← 场景 Knight_Unit |
| Skill Input Controller | ⚠️ Indicator ← 同物体上的 SkillIndicator 组件 |
| Skill Indicator | Mat ← RingMat（材质） |
| Combat Feedback（M1收尾包新增） | 无拖线槽 |

### Canvas
| 组件 | 槽 ← 拖什么 |
|---|---|
| HUD | Gold Text ← GoldText；Level Text ← LevelText；Message Text ← MessageTex |
| UIManager | Inventory Root ← PanelRoot（Canvas 下装着两个面板的总根） |
| Inventory UI | Player Inv ← 可留空（代码自动找玩家单位）；Chest Grid ← ChestPanel 下的格子容器；Player Grid ← PlayerPanel 下的格子容器；Slot Bg ← 格子底图精灵 |
| Skill Bar UI | 四组数组各拖 4 个：Icons←各 Slot 的 Icon；CD Masks←CDMask；Key Labels←Key；Cost Labels←Cost |
| Pause Manager | Pause Panel ← PausePanel |

### 场景根其他
| 物体 | 组件槽 ← 拖什么 |
|---|---|
| Wave Spawner | Unit Prefabs（按波次数组）← Minion/Warrior/SkeletonArcher_Unit 预制体 |
| GameFlow | 无槽 |
| Chest | Lid ← 宝箱盖子子物体；另需 Interactable + Box Collider（无拖线） |
| Fog | Fog Of War ← 挂本物体即可（网格/材质代码自建，Shader=Dungeon/FogOfWar，无拖线槽）；放 (0,8,0)，Map Size 210 |
| EventSystem | 不用动（UI 点击必需，丢了全按钮失灵） |

## 二、单位预制体（通用结构：根=逻辑，子模型=表现）

### Knight_Unit
| 挂哪 | 组件 | 槽 ← 拖什么 |
|---|---|---|
| 根 | Unit Health | 🔴 Stats ← Knight 资产（空=报错红字+队伍失灵） |
| 根 | Unit Mana | 无槽（数值在检查器） |
| 根 | Unit Animator Speed | Stats ← Knight 资产 |
| 根 | Character Brain | 🔴 Stats ← Knight 资产；Combat ← 根上 SwordSwing；Unit Animator ← 子物体 Knight 的 Animator |
| 根 | Skill System | ⚠️🔴 Mana ← 根 UnitMana；⚠️🔴 Sword ← 根 SwordSwing；⚠️🔴 Skills[0] ← Q_Bash；Skills[1] ← W_HeavySlash（⚠️⚠️ 本次 Q 无反应的头号排查点：此组件若 Missing/槽空，按 Q 完全静默） |
| 根 | Sword Swing | Sword ← 武器子物体；Shield ← 盾子物体；Weapon ← WeaponData 资产；Ring Material ← RingMat；Trail Material ← 拖尾材质；Stats ← Knight 资产；Health ← 根 UnitHealth |
| 根 | Selectable | Selection Ring ← 子物体上的圈；Hotkey Index = 1 |
| 根 | Inventory | 无引用槽（容量数值） |
| 子 Knight | Animator | Controller ← Knight.controller；Avatar ← KnightAvatar |
| 子 UnitHealthBar | World Health Bar | Canvas ← 自身；Hp Fill ← HPFill；Mana Fill ← MPFill；🔴 Health ← 根 UnitHealth；Mana ← 根 UnitMana |

### Archer_Unit（Knight 变体，差异项）
| 挂哪 | 组件 | 槽 ← 拖什么 |
|---|---|---|
| 根 | Unit Health / Unit Animator Speed / Character Brain | Stats ← Archer 资产；Combat ← **RangedCombat**；Unit Animator ← 子 Ranger 的 Animator |
| 根 | Skill System | Mana ← UnitMana；Sword 槽**留空**（弓手无剑）；Skills 数组大小 0 |
| 根 | Ranged Combat | 🔴 Bow ← 子 Ranger 的 handslot.r 下的弓；🔴 Arrow Prefab ← Arrow 预制体；Stats ← Archer 资产；Health ← 根 UnitHealth；Attack Trigger=`Attack`；Draw State=`Attack_Draw`；Release State=`Attack_Release` |
| 根 | Selectable | Hotkey Index = 2 |
| 子 Ranger | Animator | Controller ← Archer.controller；🔴 Avatar ← Ranger.fbx 展开拖 **RangerAvatar**（错拖 KnightAvatar=动画全废） |
| 子 Ranger | Capsule Collider | 中心(0,0.6,0) 高1.2 半径0.4；Culling Mode 检查在 Animator 上：Always Animate |

### SkeletonMinion / SkeletonWarrior（近战骷髅）
| 挂哪 | 组件 | 槽 ← 拖什么 |
|---|---|---|
| 根 | Unit Health | 🔴 Stats ← 对应骷髅资产；Part Type = Weak |
| 根 | Monster Brain | Use Own Attack Anim ✓勾选；Combat 槽**留空**；Attack Trigger=`AttackMelee`；Attack State Name=`Attack_Melee` |
| 根 | Unit Animator Speed | Stats ← 对应骷髅资产 |
| 子模型 | Animator | Controller ← Skeleton.controller；Avatar ← 该骷髅 FBX 的 Avatar；Culling Mode = Always Animate |
| 子 UnitHealthBar | World Health Bar | 同骑士；MP_Back 物体**禁用**（骷髅无蓝条） |

### SkeletonArcher_Unit（骷髅弩手）
| 挂哪 | 组件 | 槽 ← 拖什么 |
|---|---|---|
| 根 | Unit Health | Stats ← SkeletonArcher 资产；Part Type = Normal |
| 根 | Monster Brain | Use Own Attack Anim **取消勾选**；🔴 Combat ← 根上 RangedCombat；Attack Trigger=`AttackMelee`；Attack State Name=`Shoot` |
| 根 | Ranged Combat | 🔴 Bow ← 子模型 handslot.r 下的弩；🔴 Arrow Prefab ← Arrow 预制体；Stats ← SkeletonArcher 资产；Health ← 根 UnitHealth；Attack Trigger=`AttackRanged`；Draw State 留空；Release State=`Shoot` |
| 根 | Unit Animator Speed | Stats ← SkeletonArcher 资产 |
| 子模型 | Animator | Controller ← Skeleton.controller（全家共用，无独立弓手控制器）；Avatar ← 该 FBX 的 |

### UnitHealthBar 预制体（5 单位共用）
Canvas：Render Mode = World Space，120×36，Scale 0.01；HP_Back 100×10 黑A0.6 射线关；HPFill 锚点轴心左=绿；MP_Back 100×6 黑A0.6 射线关；MPFill 锚点轴心左=蓝。

## 三、资产类拖线
| 资产 | 字段 ← 内容 |
|---|---|
| Q_Bash（SkillData） | 🔴 Effects[0] ← Q_Bash_Effect（SkillEffectBase 资产，没有它 Q 按了静默无反应） |
| W_HeavySlash（SkillData） | Effects[0] ← W_Slash_Effect |
| Arrow 预制体 | 物体上挂 Projectile 组件（无拖线），缩放细长 |
| 各 UnitStats | Team 字段逐字符核对：Knight/Archer=Player；三个骷髅=Monster |

## 四、🔴 Q 无反应专项排查路径（按此序 3 分钟）
1. 选中骑士 → Skill System 组件：Missing？→ 改名时 GUID 断了（见 API 文档附录 A）
2. Skill System 三槽：Mana / Sword / Skills[0] 是否都拖着（Skills[0] 空 = 静默）
3. 项目窗口 Q_Bash 资产 → Effects 数组：大小 1？元素拖了 Q_Bash_Effect？
4. Managers → Skill Input Controller → Indicator 槽：Missing/None？
5. 按 Q 时骑士选中了吗（脚下黄圈）？没选中按 Q 本来就静默
